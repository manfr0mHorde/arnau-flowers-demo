# ARNAU Flowers: персональная демонстрационная витрина

Независимый неофициальный концепт. Фотографии заменены декоративными иллюстрациями; товары и цены демонстрационные. Без связи с другими сайтами.

Каталог, корзина, выбор филиала, форма доставки, номер для удалённого счёта Kaspi, предпросмотр заказа и передача его в WhatsApp после действия покупателя. Кабинет флориста и статистика только локально в браузере.

При запуске коммерческой версии нужны разрешение магазина, защищённая авторизация, база данных и синхронизация. Оплаты не подтверждаются автоматически.

Использована публично индексируемая аватарка аккаунта @arnauflowers и ссылки на его публикации для изображений каталога. Это не официальный сайт и не утверждённый прайс; магазин должен разрешить использование фото и подтвердить информацию перед коммерческим запуском. Instagram может ограничить доступ к изображениям; тогда включается декоративная иллюстрация.
